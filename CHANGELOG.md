# Changelog

All notable changes to this original toolkit are recorded here. Dates use the Asia/Shanghai calendar date.

## Unreleased

### Added

- A runnable triage example that turns a synthetic bug report into an intent brief, expected failing assertions, a bounded repair, the same passing verification, and an evidence review. Its verdict requires every stage gate, so import, syntax, harness, before-repair pass, after-repair failure, and review-only failure produce `needs-work`.
- Installation regression tests that execute the documented copy snippets, compare the installed skill file for file, resolve local links, exercise the refusal guard, and leave user content unchanged, plus negative mutation tests for false-positive example verdicts.
- A lightweight standard-library commit-message check with negative tests.

### Changed

- Rewrote the English and Simplified Chinese README files around product value, guarded project-local installation, a runnable first workflow, ten-skill navigation, and concise rights notes.
- Moved host compatibility references and the detailed untested boundary into the validation guide.
- Added Conventional Commits guidance and grouped-change expectations to the contribution guide.

## 0.1.0 - 2026-11-18

### Added

- Ten focused Agent Forge skills covering intent alignment, signal-first context, disposable prototypes, architectural constraints, verification harnesses, triage-reproduction-repair, evidence-first review, depth-first parallelism, context budgets, and formal verification boundaries.
- Local source maps and on-demand field guides for every skill.
- A standalone `LICENSE` and `NOTICES.md` in every skill folder so a selected-folder copy keeps its rights notes.
- A synthetic smoke case and expected artifact schema in every skill.
- English and Simplified Chinese README files with workflow choice guidance, guarded installation, examples, validation, attribution, and limits.
- A central source catalogue with canonical metadata, reciprocal skill mappings, and duplicate-URL protection.
- An offline standard-library validator, an offline smoke-case validator, a unittest suite with negative mutation tests, and a GitHub Actions workflow.
- A restricted string-scalar frontmatter profile with negative tests for unsupported YAML constructs.
- A release manifest and fail-closed publication checks for forbidden artifacts, oversized files, and unexpected files.
- A synthetic worked example clearly labeled as illustrative rather than a behavioral evaluation.
- MIT licensing for original work and a separate third-party notices file.
